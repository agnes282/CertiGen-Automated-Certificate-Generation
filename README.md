# CertiGen — Automated Certificate Generation and Management System

## Project Overview

CertiGen is a certificate generation project developed using Microsoft Excel, Microsoft Word, and Mail Merge. It uses structured student information to generate personalized certificates efficiently.

## Objectives

- Organize student records in Microsoft Excel.
- Analyze student marks and department-wise performance.
- Design a reusable certificate template in Microsoft Word.
- Automate certificate generation using Mail Merge.
- Reduce repetitive manual data entry and maintain consistent formatting.

## Technologies Used

- Microsoft Excel
- Microsoft Word
- Microsoft Word Mail Merge
- PDF Export, if implemented

## Features

- Student data management.
- Department-wise student count and marks analysis.
- Student information lookup using Excel formulas.
- Personalized certificate generation using Mail Merge.
- Reusable certificate template.

## Project Structure

- `Excel/` — Student data and analysis workbook.
- `Certificate/` — Certificate template.
- `Documentation/` — Project proposal and documentation.
- `Screenshots/` — Images demonstrating the project.
- `Demo/` — Demonstration materials.

## How It Works

1. Student information is organized in an Excel worksheet.
2. Excel formulas are used to analyze department-wise marks and retrieve student details.
3. A certificate template is designed in Microsoft Word.
4. The Excel workbook is connected to Word using Mail Merge.
5. Personalized certificates are generated for the selected student records.
